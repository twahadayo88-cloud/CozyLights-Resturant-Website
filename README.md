# 🍽️ Cozy Lights

Cozy Lights is a modern luxury restaurant website crafted to deliver an elegant and immersive digital dining experience through premium design, smooth user interactions, and responsive performance.

## ✨ Features

- Modern Luxury UI/UX
- Fully Responsive Design
- Interactive Digital Menu
- Online Table Reservation System
- Chef's Special Showcase
- Customer Testimonials
- Restaurant Gallery
- Smooth Animations & Transitions
- Mobile-Friendly Experience

## 🛠 Tech Stack

- React
- JavaScript / TypeScript
- Tailwind CSS
- Framer Motion
- Modern Frontend Development Practices

## 🎯 Purpose

Built to showcase modern frontend development, responsive web design, user experience principles, and business-oriented web solutions through a premium restaurant website.
